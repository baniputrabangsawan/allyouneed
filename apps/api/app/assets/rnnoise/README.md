# RNNoise model

`cb.rnnn` is GregorR’s conjoined-burgers (2018-08-28) RNNoise model for FFmpeg `arnndn`.

- Source: https://github.com/GregorR/rnnoise-models
- Path: `conjoined-burgers-2018-08-28/cb.rnnn`
- License: follow the upstream RNNoise / rnnoise-models terms (BSD-style).

Override the path with `RNNOISE_MODEL_PATH` if you need a different `.rnnn` file. Smart Noise Reduction fails if the file is missing; it does not fall back to Standard.
